# MAXX AI SOCIAL SYSTEM

## 1. 品牌定位
品牌名稱：MAXX
專業領域：男士髮型設計
核心技術：男士燙髮、紋理燙、髮型改造

## 2. 目標客群
主要客群：男性
客群特徵：
- 重視外表與個人形象
- 願意投資自己的造型
- 希望髮型有個性與辨識度
## 3. 客戶需求與痛點
- 細軟髮缺乏蓬鬆感
- 頭頂容易扁塌
- 後腦勺不夠立體
- 不知道如何整理頭髮
- 希望燙完能自然好整理

## 4. 核心服務
- 凌亂紋理燙
- 前刺燙
- 中分紋理燙
- 男士造型設計
- 依照頭型與髮質設計燙髮

## 5. 品牌個性
- 有態度
- 有個性
- 專業技術派
- 不使用制式公版文案
- 重視實際髮型效果

## 6. Instagram 經營目標
第一目標：增加實際預約
第二目標：增加有效私訊
第三目標：提升品牌曝光與粉絲數

## 7. AI 文案規則
- 使用自然、有個性的繁體中文
- 以男性客群為主要溝通對象
- 強調髮型能解決的問題
- 強調燙髮後的造型優勢
- 避免誇大不實的效果
- 每篇內容都要有明確預約引導
